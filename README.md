# 세이프픽스 상도점 · 2D 게임 스타일 리디자인

크림·남색·주황 색감, 굵은 외곽선과 그림자, 큰 글씨, 말풍선·STAGE 태그 같은 2D 게임 요소로 전체 디자인을 다시 만들었습니다.

## 실행
npm install 후 npm run dev. 배포용 정적 파일은 npm run build로 생성되는 dist 폴더입니다.

## 바뀐 구성
- store.ts: 매장 이름·주소·전화·영업시간·네이버 플레이스·당근 링크·쿠폰 정보. 정보가 바뀌면 이 파일만 고치면 전체에 반영됩니다.
- components/Characters.tsx: 2D 게임 스타일 SVG 캐릭터(폰·패드·배터리·데이터 폴더), 매장 일러스트, 반짝이. 표정(happy/wink/wow)과 포즈(wave/point/cheer/hold)를 고를 수 있고, 눈 깜빡임·손 흔들기 애니메이션이 있습니다.
- App.tsx: 메인(배너 → 전화·네이버·당근 바로가기 → 기기 선택 → 믿고 맡기는 이유 → 쿠폰 → 매장 위치 → 후기 → 공지), 매장 안내, FAQ, 상담 페이지.
- pages/CarePage.tsx: 수리하기·배터리·데이터 게임 스테이지 페이지.
- index.css: 전체 스타일. 본문 18px 기준, 모바일 대응, 동작 줄이기 설정 지원.

기존 3D 이미지(public/images/safefix-friends.png)는 더 이상 쓰지 않지만 파일은 남겨두었습니다.
상담 메모는 브라우저 안에서만 만들어지고 매장으로 전송되지 않습니다. 검토용 noindex 상태이며, 공개할 때 index.html의 robots 메타 태그를 지워주세요.
