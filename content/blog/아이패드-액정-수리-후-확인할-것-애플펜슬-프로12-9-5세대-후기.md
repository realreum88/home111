**아이패드 액정을 교체했다면 화면만 켜지는지 보지 말고, 애플펜슬이 화면 전체에서 끊김 없이 써지는지부터 확인하세요.** 화면은 멀쩡히 나와도 펜슬이 끊기는 경우가 있고, 특히 아이패드 프로 12.9 5세대·6세대는 액정 교체 후 ROM 작업을 거치지 않으면 펜슬이 끊겨요. 펜슬로 필기하고 강의를 듣는 학생이라면 이 부분이 수리의 절반이에요.

| 확인 항목 | 확인 방법 | 이상하면 의심할 부분 |
|---|---|---|
| 애플펜슬 | 메모 앱에서 화면 전체를 끝까지 그어보기 | 펜슬 끊김: ROM 작업 누락·액정 불량 |
| 화면 표시 | 밝은 화면에서 줄·얼룩·멍 확인 | 액정 불량 |
| Face ID | Face ID 설정 화면에서 얼굴 인식 시작 | 상단 센서 연결 |
| 영상·고사양 앱 | 유튜브·고사양 앱을 틀어 버벅임·이상 현상 확인 | 액정·연결 불량 |

## 01 아이패드 액정 수리 후 가장 먼저 확인할 것은 무엇인가요?

**애플펜슬이에요. 메모 앱을 열고 화면 위쪽 끝부터 아래쪽 끝까지, 가장자리까지 빠짐없이 그어보세요.** 선이 중간에 끊기거나, 특정 구역에서만 선이 안 그어지거나, 선이 늦게 따라온다면 수리 직후 바로 수리점에 말씀하셔야 해요.

세이프픽스는 중앙대·숭실대 앞에 있어서 아이패드를 맡기시는 손님 대부분이 학생이에요. 애플펜슬로 과제를 하고 강의를 들으시기 때문에, 액정 교체 후에는 펜슬 상태를 가장 꼼꼼하게 확인하고 출고해요. 그래서 펜슬이 중요한 수험생과 학생분들이 멀리서 [택배수리](/delivery)로 맡겨주시기도 해요.

![애플펜슬 테스트: 화면 위쪽부터 아래쪽 끝까지 선이 끊기지 않고 이어져요](/images/posts/ipad-pro129-5-pencil-test-angle.webp)

## 02 아이패드 프로 12.9는 왜 액정 교체 후 펜슬이 끊기나요?

**아이패드 프로 12.9 5세대와 6세대는 액정만 바꾸면 애플펜슬이 끊기는 모델이라, 교체 후 ROM 작업을 해줘야 해요.** 기존 화면 케이블에 있는 ROM(EPROM) 칩의 정보를 새 화면으로 옮겨야 펜슬이 정상 동작해요.

| 모델 | 액정 교체 후 펜슬 | 필요한 작업 |
|---|---|---|
| 아이패드 프로 12.9 5세대 | ROM 작업 없이 교체하면 끊김 | 기존 화면의 ROM 작업 |
| 아이패드 프로 12.9 6세대 | ROM 작업 없이 교체하면 끊김 | 기존 화면의 ROM 작업 |

이 과정을 모르는 수리점이 많아요. 그래서 액정 교체 후 펜슬이 끊긴 채로 출고되거나, 아예 이 모델은 수리하지 않는 곳도 많아요. 수리를 맡기기 전에 "액정 교체 후 펜슬 ROM 작업까지 해주시나요?"라고 물어보시면 좋아요.

액정 교체 후 펜슬이 끊기는 다른 원인(새 액정의 외부 유리 불량, 메인보드 문제)은 [아이패드 액정 교체 후 애플펜슬이 끊기는 이유](/services/ipad-screen/아이패드-액정-교체-후-애플펜슬-끊김-이유-외부유리-메인보드-수리-후기)에 따로 정리해 뒀어요.

## 03 펜슬 말고 또 무엇을 확인해야 하나요?

**화면 표시, Face ID, 그리고 영상·고사양 앱 재생까지 확인해야 해요.** 정지된 화면에서는 멀쩡해 보여도, 화면이 빠르게 바뀔 때만 드러나는 이상이 있기 때문이에요.

1. **화면 표시**: 밝은 화면에서 줄, 얼룩, 멍이 없는지 봐요.
2. **Face ID**: 설정의 Face ID 및 암호에서 얼굴 인식 설정을 시작해 정상 동작하는지 확인해요.
3. **영상·고사양 앱 테스트**: 유튜브 같은 영상이나 고사양 앱을 틀어놓고, 해상도가 정상으로 나오는지, 버벅거림이나 화면 이상 현상은 없는지 확인해요.
4. **모델 정보 확인**: 설정 → 일반 → 정보에서 모델이 정상으로 인식되는지 봐요.

![유튜브 영상을 재생하며 해상도와 버벅거림, 화면 이상 현상을 확인하는 모습 (영상 내용은 가렸어요)](/images/posts/ipad-pro129-5-video-test.webp)

![설정 정보 화면: 모델명 iPad Pro 12.9(5세대)](/images/posts/ipad-pro129-5-model-info.webp)

## 04 아이패드 프로 12.9 5세대 액정 교체는 어떻게 진행됐나요?

**정품 추출 액정으로 교체하고 ROM 작업을 한 뒤, 펜슬·Face ID·영상 테스트까지 마치고 출고했어요.**

### 아이패드 액정 수리 후기: 아이패드 프로 12.9 5세대, 전면 유리 파손과 내부 패널 손상

전면 유리가 화면 전체에 걸쳐 깨졌고, 안쪽 패널까지 심하게 손상돼 화면에 검은 줄이 생긴 상태로 오셨어요.

![아이패드 프로 12.9 5세대 수리 전: 전면 유리가 화면 전체에 걸쳐 깨진 상태](/images/posts/ipad-pro129-5-broken-glass.webp)

![화면을 켜면 내부 패널 손상으로 검은 줄이 생겨요](/images/posts/ipad-pro129-5-broken-panel-lines.webp)

1. **전류 확인**: 전원 공급기로 5V를 넣고 전류를 확인하며 기기 상태를 봐요.
2. **화면 분리**: 깨진 액정을 분리하고 내부 상태를 확인해요.
3. **정품 추출 액정 교체**: 정품에서 추출한 액정으로 교체해요.
4. **ROM 작업**: 기존 화면의 ROM 정보를 새 화면으로 옮겨 애플펜슬이 정상 동작하게 해요.
5. **출고 전 테스트**: 애플펜슬 전 영역 필기, Face ID, 영상·고사양 앱 재생 테스트를 해요.

![전원 공급기로 5V를 넣고 전류를 확인하는 모습](/images/posts/ipad-pro129-5-current-off.webp)

![전원이 켜진 상태에서 전류를 확인하는 모습](/images/posts/ipad-pro129-5-current-on.webp)

![아이패드 프로 12.9 5세대 분해: 화면을 분리한 내부 모습](/images/posts/ipad-pro129-5-opened.webp)

![아이패드 프로 12.9 5세대 내부: 배터리와 화면 연결부](/images/posts/ipad-pro129-5-inside-battery.webp)

| 수리 전 | 수리 후 |
|---|---|
| 전면 유리 전체 파손 | 정품 추출 액정으로 교체 |
| 내부 패널 손상으로 검은 줄 | 화면 정상 표시 |
| - | ROM 작업으로 애플펜슬 끊김 없음 |
| - | Face ID·영상 재생 정상 |

## 내 아이패드도 수리 후 점검이 필요할까요?

액정을 교체한 뒤 아래 중 하나라도 해당하면 수리한 곳에 바로 말씀하세요.

1. 애플펜슬 선이 중간에 끊기거나 특정 구역에서 안 그어져요.
2. 화면에 줄, 얼룩, 멍이 보여요.
3. Face ID가 안 되거나 설정이 시작되지 않아요.
4. 영상을 틀면 버벅거리거나 화면이 이상하게 나와요.

세이프픽스는 먼저 상태를 확인하고, 수리 범위와 비용을 안내드린 뒤 동의하실 때 수리를 진행해요. 액정 교체 후에는 펜슬 테스트를 마친 뒤에만 출고해요.

## 자주 묻는 질문

### 아이패드 액정 교체 후 펜슬이 끊기면 다시 액정을 바꿔야 하나요?

꼭 그렇지는 않아요. 아이패드 프로 12.9 5세대·6세대는 ROM 작업이 빠져서 끊기는 경우가 있어요. 어떤 원인인지 먼저 확인해야 해요.

### 아이패드 프로 12.9 5세대도 사설에서 액정 수리가 되나요?

네. 이번 사례처럼 정품 추출 액정으로 교체하고 ROM 작업까지 하면 애플펜슬도 정상으로 쓸 수 있어요.

### 멀리 살면 택배로도 아이패드 액정 수리를 맡길 수 있나요?

네. 상도동 매장에서 대표가 직접 수리하고, 먼 곳은 택배로 맡기실 수 있어요. 자세한 방법은 [택배수리](/delivery)에서 확인하실 수 있어요.

## 액정을 바꾼 뒤 펜슬 테스트, 해보셨나요?

화면이 나온다고 수리가 끝난 건 아니에요. 펜슬로 필기하고 강의를 듣는다면, 화면 전체를 한 번씩 그어보는 것만으로도 문제를 미리 찾을 수 있어요. 자세한 안내는 [아이패드 액정수리](/services/ipad-screen)에서 확인하실 수 있어요.
