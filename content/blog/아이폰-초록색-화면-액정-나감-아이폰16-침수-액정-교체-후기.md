**아이폰 화면이 초록색으로 변하고 깜빡이다 나간다면, 깨진 곳이 없어도 습기나 침수로 액정이 손상됐을 수 있어요. 이럴 때는 액정을 교체해야 하고, Face ID를 계속 쓰려면 기존 전면 센서를 새 액정으로 옮겨야 해요.** 겉이 멀쩡해서 원인을 모르고 넘어가기 쉬운데, 습관을 바꾸지 않으면 같은 고장이 다시 생길 수 있어요.

| 확인할 점 | 이번 아이폰 16 | 수리 방법 |
|---|---|---|
| 화면 증상 | 초록색 화면, 깜빡이다 나감 | [아이폰 액정수리](/services/iphone-screen) |
| 겉모습 | 깨진 곳·물에 빠뜨린 적 없음 | 분해 후 내부 확인 |
| 내부 상태 | 열어보니 물비린내 | 정품 액정으로 교체 |
| Face ID | 전면 센서가 액정에 붙어 있음 | 기존 전면 센서 이식 |

## 01 아이폰 화면이 초록색으로 나오는 이유는 무엇인가요?

**액정이 손상됐다는 신호예요. 그동안 수리해 보면 침수나 습기로 액정이 손상됐을 때 화면이 초록색으로 바뀌는 경우가 많았어요.** 이번 아이폰 16도 화면 전체가 초록색으로 나오다가 중간중간 깜빡이며 꺼지는 증상으로 오셨어요.

![아이폰 16 수리 전: 화면 전체가 초록색으로 나오는 상태](/images/posts/iphone16-green-screen-before.webp)

![아이폰 16 뒷면: 깨지거나 물에 빠진 흔적 없이 겉은 멀쩡해요](/images/posts/iphone16-green-back.webp)

## 02 떨어뜨리거나 물에 빠뜨린 적이 없는데 왜 액정이 나가나요?

**물에 직접 빠뜨리지 않아도, 샤워할 때처럼 습기가 많은 곳에서 쓰는 습관이 원인이 될 수 있어요.** 이번 손님도 깨지거나 물에 빠뜨린 적은 없었지만, 열어보니 내부에서 물비린내가 났어요. 여쭤보니 샤워할 때 아이폰을 들고 들어가는 습관이 있으셨어요.

Apple도 액체 손상을 막으려면 샤워할 때처럼 압력이 있거나 빠른 물줄기에 아이폰을 노출하지 말고, 사우나나 증기가 많은 곳에서 쓰지 말라고 안내해요. 방수·방진 성능은 영구적이지 않고 쓰면서 약해질 수 있으며, 액체 손상은 보증 대상이 아니라고 밝히고 있어요([Apple: iPhone 7 이후 모델의 방수 및 방진](https://support.apple.com/HT207043), [Apple: iPhone 취급 정보](https://support.apple.com/en-kg/guide/iphone/important-handling-information-iphbbe12ba1/14.0)).

| Apple이 피하라고 안내하는 상황 | 이유 |
|---|---|
| 샤워할 때 들고 가기 | 압력이 있거나 빠른 물줄기에 노출 |
| 사우나·증기가 많은 곳에서 사용 | 높은 습기 |
| 수영·목욕할 때 사용 | 물에 잠김 |

![아이폰 16 내부 확대: 화면을 분리한 뒤 프레임과 전면 카메라 쪽 상태](/images/posts/iphone16-green-opened-closeup.webp)

## 03 액정을 바꾸면 Face ID는 어떻게 되나요?

**Face ID를 계속 쓰려면 기존 액정에 붙어 있던 전면 센서를 새 액정으로 옮겨 달아야 해요.** 전면 센서는 액정 뒤쪽에 붙어 있어서, 액정만 새것으로 바꾸고 센서를 옮기지 않으면 Face ID를 쓸 수 없어요.

![기존 액정 뒤쪽의 전면 센서: 새 액정으로 옮겨 달아야 Face ID를 쓸 수 있어요](/images/posts/iphone16-green-front-sensor.webp)

## 04 아이폰 16 초록색 화면은 어떻게 고쳤나요?

**내구성이 좋은 정품 액정으로 교체하고, 기존 전면 센서를 이식한 뒤 Face ID와 전후면 카메라를 테스트하고 출고했어요.**

### 아이폰 액정수리 후기: 아이폰 16, 샤워 습관으로 생긴 초록색 화면

1. **증상 확인**: 초록색 화면과 깜빡임, 꺼짐 증상을 확인해요.
2. **분해·내부 확인**: 화면을 열어 내부 상태를 확인해요. 이번에는 물비린내가 났어요.
3. **정품 액정 교체**: 내구성이 좋은 정품 액정으로 교체해요.
4. **전면 센서 이식**: 기존 액정의 전면 센서를 새 액정으로 옮겨 달아요.
5. **기능 테스트**: Face ID와 전면·후면 카메라를 테스트해요.
6. **주의사항 안내 후 출고**: 샤워할 때 들고 가지 않도록 안내드리고 출고해요.

![아이폰 16 액정 교체 후: 화면이 정상으로 나와요 (손님 배경화면은 가렸어요)](/images/posts/iphone16-green-after.webp)

| 수리 전 | 수리 후 |
|---|---|
| 초록색 화면, 깜빡이다 꺼짐 | 정품 액정으로 화면 정상 |
| Face ID용 전면 센서가 기존 액정에 붙어 있음 | 전면 센서 이식, Face ID 정상 |
| - | 전면·후면 카메라 정상 |

## 내 아이폰도 습기 때문일까요?

아래 중 하나라도 해당하면 점검을 받아보세요.

1. 화면이 초록색으로 변하거나 초록빛이 돌아요.
2. 화면이 깜빡이다가 꺼지기를 반복해요.
3. 깨진 곳은 없는데 화면 이상이 생겼어요.
4. 샤워할 때나 욕실에서 아이폰을 자주 써요.

세이프픽스는 먼저 상태를 확인하고, 수리 범위와 비용을 안내드린 뒤 동의하실 때 수리를 진행해요.

## 자주 묻는 질문

### 아이폰 화면이 초록색이면 꼭 액정을 바꿔야 하나요?

화면 전체가 초록색으로 나오거나 깜빡이다 꺼진다면 액정이 손상됐을 가능성이 커요. 이번 아이폰 16도 정품 액정으로 교체해 해결했어요.

### 샤워할 때 아이폰을 들고 가도 되나요?

권하지 않아요. Apple도 샤워처럼 압력이 있거나 빠른 물줄기, 사우나·증기가 많은 곳에서의 사용을 피하라고 안내해요. 방수 성능은 영구적이지 않고, 액체 손상은 보증 대상이 아니에요.

### 액정을 바꾸면 Face ID가 안 되나요?

기존 전면 센서를 새 액정으로 옮겨 달면 Face ID를 그대로 쓸 수 있어요. 이번 아이폰 16도 전면 센서를 이식한 뒤 Face ID 테스트까지 마치고 출고했어요.

## 깨진 데는 없는데 화면이 초록색으로 변했나요?

겉이 멀쩡해도 습기로 안쪽이 손상됐을 수 있어요. 더 깜빡이거나 꺼지기 전에 점검받아 보세요. 자세한 안내는 [아이폰 액정수리](/services/iphone-screen)에서 확인하실 수 있어요.
