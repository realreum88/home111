**아이폰이 물에 빠진 뒤 화면이 나갔다면, 액정만 바꾸면 끝날 수도 있지만 메인보드까지 손상됐을 가능성도 함께 봐야 해요.** 침수는 증상이 워낙 다양해서, 화면을 살려 놓고 나서야 숨어 있던 메인보드 문제가 드러나는 경우가 많아요.

| 침수 후 증상 | 의심 부위 | 이번 아이폰 14 |
|---|---|---|
| 화면이 하얗게 나가거나 안 켜짐 | 액정 | 액정 교체로 화면 출력 |
| 꺼졌다 켜지기를 반복 | 메인보드·센서·주변 부품 | panic-full 로그 반복 |
| 카메라 렌즈 안 습기 | 침수 흔적 | 렌즈 안쪽 습기로 침수 확인 |
| 부품을 바꿔도 재부팅 | 메인보드 회로 | [메인보드 수리](/services/iphone-mainboard) |

## 01 아이폰이 물에 빠지면 어떤 증상이 생기나요?

**침수 증상은 정해져 있지 않아요.** 화면만 나갈 수도, 꺼졌다 켜지기를 반복할 수도, 아예 켜지지 않을 수도 있어요. 이번 아이폰 14는 샤워를 하다가 화장실에서 물에 빠뜨린 뒤 화면이 하얗게 나가고, 꺼졌다 켜지기를 반복하다가 결국 화면이 아예 안 켜지는 상태로 오셨어요.

![샤워 중 물에 빠진 아이폰 14: 화면이 켜지지 않는 상태](/images/posts/iphone14-water-no-display.webp)

![침수된 아이폰 14 후면 카메라: 렌즈 안쪽에 습기가 차 있어요](/images/posts/iphone14-water-camera-moisture.webp)

카메라 렌즈 안쪽에 습기가 차 있는 건 물이 기기 안까지 들어갔다는 증거예요.

## 02 침수된 아이폰은 액정만 바꾸면 되나요?

**액정만 바꿔서 해결되면 다행이지만, 이번처럼 화면을 살리고 나서 다른 문제가 드러나기도 해요.** 액정을 교체해 화면이 나오자, 설정 → 개인정보 보호 및 보안 → 분석 및 향상 → 분석 데이터에 `panic-full` 로그가 짧은 간격으로 계속 쌓이고 있었어요. 기기가 스스로 오류를 감지하고 강제로 재부팅하고 있다는 뜻이에요.

![액정 교체 후 확인한 아이폰 14 분석 데이터: 몇 분 간격으로 쌓인 panic-full 로그](/images/posts/iphone14-water-panic-full-list.webp)

## 03 패닉 풀 로그는 무엇을 말해주나요?

**이번 로그에는 'SMC BSC failure'가 기록돼 있었어요. 전원과 센서를 관리하는 SMC가 다른 회로와 데이터를 주고받는 과정에서 오류가 났다는 단서예요.**

| 로그 항목 | 기록 내용 |
|---|---|
| 기기 | iPhone14,7 (아이폰 14) |
| 패닉 원인 | SMC PANIC – SMC BSC failure |
| 센서 배열 | S.sensor array 0 – 5 is 0, 6291456, 0, 0, 0 |
| 통신 오류 | i2c 오류 기록(i2c_err_sts) |

![아이폰 14 panic-full 로그: SMC BSC failure와 센서 배열 값이 기록돼 있어요](/images/posts/iphone14-water-panic-full-log.webp)

iFixit의 SMC 패닉 안내에 따르면, 이 오류는 SMC가 특정 센서로부터 받아야 할 신호를 받지 못할 때 생기고, 해결되지 않으면 약 3분마다 재부팅이 반복돼요. 센서 배열 값 6291456은 16진수로 0x600000으로, 아이폰 14 기준표에서 전면 센서(0x200000)와 무선 충전 코일(0x400000) 쪽 신호에 해당해요([iFixit: iPhone SMC Panic Assertion Failed](https://www.ifixit.com/Wiki/iPhone_SMC_Panic_Assertion_Failed)).

그래서 순서가 중요해요. **센서 부품을 먼저 교체해 보고, 그래도 해결되지 않으면 센서와 보드 사이의 통신을 담당하는 제어 칩셋이나 통신 회로 쪽을 봐야 해요.** 같은 안내에서도 부품 교체로 해결되지 않으면 메인보드를 의심해야 하고, 특히 침수된 기기라면 그 가능성이 더 크다고 설명해요.

## 04 아이폰 14 침수 패닉 풀은 어떻게 수리했나요?

**로그가 가리킨 전면 센서와 무선 충전 코일을 먼저 교체해 봐도 해결되지 않아, 센서와 보드 사이의 통신을 담당하는 제어 칩셋과 통신 회로 쪽 메인보드를 수리했어요.**

### 메인보드 수리 후기: 아이폰 14, 샤워 중 침수 후 화면 꺼짐·패닉 풀 반복

1. **액정 교체**: 화면이 나오지 않아 먼저 액정을 교체해 화면 출력을 확인해요.
2. **로그 확인**: 분석 데이터의 panic-full 로그에서 SMC BSC failure를 확인해요.
3. **전류 측정**: 전원 공급기로 5V를 넣고 전류를 측정해 상태를 봐요.
4. **센서 부품 교체**: 로그 값(0x600000)이 가리킨 전면 센서와 무선 충전 코일을 교체해 증상이 사라지는지 확인해요.
5. **메인보드 수리**: 센서 교체로도 해결되지 않아, 센서와 보드 간 통신을 담당하는 제어 칩셋과 통신 회로 쪽을 수리해요.
6. **재부팅 확인**: 수리 후 재부팅이 반복되지 않고, 새 panic-full 로그가 쌓이지 않는지 확인해요.

![전원 공급기로 5V를 넣고 전류를 측정하며 panic-full 로그를 확인하는 아이폰 14](/images/posts/iphone14-water-panic-current-test.webp)

![아이폰 14 내부: 배터리와 A15 Bionic 메인보드](/images/posts/iphone14-water-board-inside.webp)

![아이폰 14 배터리 성능 최대치 71%, '서비스' 표시: 배터리는 패닉 풀의 원인이 아니어서 교체하지 않았어요](/images/posts/iphone14-water-battery-71.webp)

배터리 성능 최대치는 71%로 '서비스' 표시가 떠 있었지만, 패닉 풀의 원인은 배터리가 아니었어요. 그래서 이번 수리에서는 배터리를 교체하지 않았어요.

로그가 가리킨 전면 센서와 무선 충전 코일부터 교체해 확인했기 때문에, 원인이 센서 자체가 아니라 메인보드의 통신 회로라는 걸 정확히 좁힐 수 있었어요. 액정만 교체하고 끝냈다면 패닉 풀은 계속 반복됐을 거예요.

| 수리 전 | 수리 후 |
|---|---|
| 화면 안 켜짐 | 액정 교체로 화면 정상 출력 |
| panic-full 로그 반복, 강제 재부팅 | 메인보드 수리 후 재부팅 멈춤 |
| 배터리 성능 최대치 71% | 71% (원인이 아니어서 교체하지 않음) |

## 아이폰이 물에 빠졌다면 바로 이렇게 하세요

아래 중 하나라도 해당하면 점검을 받아보세요.

1. 물에 빠진 뒤 화면이 하얗게 나가거나 깜빡여요.
2. 꺼졌다 켜지기를 반복해요.
3. 카메라 렌즈 안에 습기가 보여요.
4. 분석 데이터에 `panic-full` 파일이 여러 개 쌓여 있어요.

세이프픽스는 먼저 점검으로 원인을 확인하고, 수리 범위와 비용을 안내드린 뒤 동의하실 때 수리를 진행해요. 수리 전에 전원 전류를 측정하고 멀티미터로 쇼트 지점을 찾아 원인을 확인해요.

## 자주 묻는 질문

### 침수된 아이폰은 액정만 바꾸면 되나요?

액정만 손상됐다면 그걸로 해결되지만, 침수는 메인보드까지 영향을 줄 수 있어요. 이번 아이폰 14처럼 액정 교체 후 panic-full 로그가 남는다면 메인보드 점검이 필요해요.

### 아이폰 패닉 풀 로그는 어디서 확인하나요?

설정 → 개인정보 보호 및 보안 → 분석 및 향상 → 분석 데이터에서 `panic-full`로 시작하는 파일을 확인할 수 있어요.

### 아이폰 메인보드 수리는 어떻게 진단하나요?

로그로 오류 종류를 확인하고, 전원 전류를 측정해요. 그다음 로그가 가리키는 센서 부품을 먼저 교체해 보고, 해결되지 않으면 제어 칩셋과 통신 회로 같은 메인보드 쪽을 점검해요.

## 물에 빠진 뒤 화면만 고치면 된다고 생각하셨나요?

침수는 화면 뒤에 숨은 문제가 더 클 수 있어요. 화면을 살린 뒤에도 꺼졌다 켜진다면 메인보드까지 점검해 보세요. 자세한 안내는 [아이폰 메인보드수리](/services/iphone-mainboard)에서 확인하실 수 있어요.
